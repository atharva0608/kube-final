# Frontend: Context

## Purpose
React Context providers for global state.

## Responsibilities
- `AuthContext`: Manages the JWT, user profile, and active organization.
- `ThemeContext`: Manages light/dark mode preferences.
- `ToastContext`: Manages global transient notifications.

## Inputs
- Source: Application lifecycle.
- Format: Context Provider wrappers.

## Outputs
- Destination: Child components via `useContext`.
- Format: Context values.
